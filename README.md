# Homework 3 Repository Guide

## Repository Setup Instructions

1. Navigate to the course assignment template.
2. Click the green **Use this template** button in the top right corner of the repository page.
3. Click "create a new repository".
4. Under **Owner**, select this organization (uh-manoa-ics212-f26).
5. Set the repository **Visibility** to **Private**.
6. Name your repository exactly like this: assignment-03-your_uh_username

---

## Provided Files

Within the template you will have the following files that are currently empty.

* `temperature.c`: Your code for the Temperature Conversion Functions problem.
* `classify.c`: Your code for the Number Classification problem.
* `digits.c`: Your code for the Digit Analysis problem.
* `shipping.c`: Your code for the Integrated Program: Shipping Cost Calculator problem.
* `written_response.txt`: Contains your written answers and explanations for each required problem section.

---

## Submission

Please **push** all code and necessary files to your repository before the assignment deadline. 

## Late Work Policy

Assignments may be submitted up to **24 hours late with a 20% grade penalty**. Assignments submitted more than 24 hours after the deadline will not be accepted, except in circumstances approved by the instructor.
